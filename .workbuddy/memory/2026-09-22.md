## 引擎设计问题审查（未改代码，仅静态阅读）
梳理出以下关键缺陷，作为后续重构的输入：

### 致命级（架构断裂）
1. **Effect 系统从未接线到引擎**：`EffectRegistry` / `SkillRegistry` 只在 `__tests__` 中被实例化，GameEngine / GameBoot 生产代码从未调用 `registerAll` / `loadHeroSkills`。→ 真实对局中 `EventTrigger.handlers` 恒为空，所有卡牌效果与武将技能完全不生效。同理 `damageSystem.registerHook` 从未被调用，6 段伤害流水线是空的。
2. **`rebindState()` 导致 EventDispatcher 的 deps 失效**：deps 在构造函数中 `buildEffectDeps()` 一次性捕获，init 时 `this.state` 与全部子系统被重建，但 deps 未更新、EventDispatcher 也没有 setDeps。→ EffectContext 操作的是被废弃的空 GameState，与 PhaseManager 持有的新 state 不一致。
3. **伤害结算双轨制**：DamageSystem 自建 DamageStage 流水线，与事件系统的 TriggerStage 并行且互不相通。`EffectContext.damageTarget` 先 `executePipeline`（已扣血）再 `dispatch(Damage)` 事件，顺序颠倒，技能无法拦截伤害。

### 严重级
4. EventChain 名不副实的 LIFO：`dispatchAll` 先 pop 再 dispatch（内部又 push）；`processNestedEvents` 只在 Content 阶段后处理，Before/End/After 阶段产生的子事件被延迟。「后发先至」与无懈可击式插入取消均无实现路径（`canceled` 仅在 SkipCheck 检查一次）。
5. 没有「结算点 / 按座次轮询询问」模型，PriorityManager 只按 priority + isLocked 排序，缺少从当前行动玩家起的座次顺序。
6. 直接改状态泛滥，违反 CLAUDE.md 守则第 1 条：`DamageSystem.applyDamage` 直接 `target.hp -=`，`EffectContext.recoverHp / modifyMaxHp / drawCards`、`GameEngine.dealInitialHands`、`PhaseManager.doPhaseDraw/doPhaseDiscard` 均绕过事件与 CardSystem。
7. DamageSystem 钩子全局注册，无持有者归属、无 filter、无优先级、执行顺序即注册顺序。
8. 主公未固定在 0 号位（`assignRoles` 整体 shuffle 身份），而 TurnManager 从 0 号起手 → 先手权规则错误，与 PLAN.md「主公总是玩家0」矛盾。
9. 非确定性随机：`fisherYatesShuffle` / `DefaultRandomService` 用 `Math.random()`，无法 seed → 回放（ReplayEngine）与确定性测试不成立。

### 可维护性级
10. trigger 四 scope（source/player/global/target）语义混乱；`player` scope 依赖 `event.player`，而多数事件创建时未传 player → 该 scope 实际永不触发。CLAUDE.md 只记录了 3 个 scope。
11. 状态机当前状态与 `state.currentPhase` 双写；`registerState(WILDCARD, [GameOver])` 通配注册易与具体转移冲突。
12. `IEffect` 接口膨胀；`frequency`（once/unlimited/oncePerTurn/oncePerRound）无落地执行点；`SkillRegistry.enableEffect/disableEffect`、`EffectContext.modifyEffects` 均为空桩（后者只存了数组长度）。
13. `EventTrigger.getMatchingHandlers` 每个 stage 全量 filter 注册表。
14. 静默失败：`EventDispatcher.createContext` 找不到玩家返回 undefined 直接跳过 handler；多处 `catch {}` 吞异常。
15. 疑似类型错误：`src/core/engine/effect-context.ts:32` 使用 `IGameState` 但未 import（node_modules 未安装，未能跑 type-check 验证）。
