### T1 — D5 / D6：两处重复条件（最高优先，先确认再修）

```
target-system.ts:152   tags.has(CardTag.Heal) && tags.has(CardTag.Heal)
phase-manager.ts:570   card.tags.has(CardTag.Heal) || card.tags.has(CardTag.Heal)
```

两处都是**同一个 tag 与自己重复**。`&&` 是恒等式（等于只判一次），`||` 也是恒等式。
紧邻的杀那行是 `Strike && Attack`，对仗看像是漏了第二个 tag。

**要求**：

1. **先判定原意**：查 `src/source/cards/*` 里治疗类牌实际带的 tags，
   以及该判定要覆盖的牌类，说明第二个 tag 本该是什么、依据是什么。
2. **能判定** → 修，并加断言（钉住该类牌的目标范围）。
3. **判不出来** → **不改代码**，只登记为「待裁决」，并在交付里说明卡在哪。
   **不要猜一个 tag 填进去。**
